# Migrating from 0.2 to 1.0

PSPSO 1.0 intentionally removes compatibility execution paths. There is no
deprecation bridge.

| Removed 0.2 usage | PSPSO 1.0 replacement |
| --- | --- |
| `from pspso import pspso` | `from pspso import optimize` or `PSPSOOptimizer` |
| `fitpspso(...)` | `OptimizationConfig(strategy="pso")` and `optimize(...)` |
| `fitpsgrid(...)` | `OptimizationConfig(strategy="grid")` |
| `fitpsrandom(...)` | `OptimizationConfig(strategy="random")` |
| Tuple return values | `OptimizationResult` fields and `trials_frame()` |
| `print_results()` | `result.summary()` or notebook display |
| Static prediction cost helper | `result.evaluate(X, y)` |
| List search-space values | Typed `Choice`, `IntRange`, `FloatRange`, or `LogFloatRange` |
| `pspso-run file.json` | `pspso run start file.json --wait` |
| `acc` / `auc` | `accuracy` / `roc_auc` |
| `gbdt` | `lightgbm` |
| `mlp` / `torch_mlp` | `sklearn_mlp` / `pytorch_mlp` |
| Task names containing spaces | `binary_classification` / `multiclass_classification` |
| `/api/...` | `/api/v1/...` |

Scenario files must use `schema_version: 1` and the typed JSON domain format.
Unknown fields and removed aliases produce validation errors.

The 1.0 workspace starts at `.pspso/v1/`. Earlier databases and artifacts in
`.pspso/` remain untouched but are not displayed or migrated.
